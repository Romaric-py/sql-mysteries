SQL Murder Mystery

Trouverez-vous le coupable ?

Un meurtre a été commis à SQL City ! Le SQL Murder Mystery est conçu à la fois comme une leçon autonome pour apprendre les concepts et commandes SQL, et comme un jeu amusant permettant aux utilisateurs expérimentés de résoudre un crime intrigant.

Débutant en SQL ?

Cet exercice est davantage conçu comme un moyen de pratiquer le SQL que comme un cours complet. Si vous n'avez jamais utilisé SQL, suivez le guide pas-à-pas. Si vous souhaitez vraiment approfondir le SQL, vous préférerez peut-être un tutoriel complet comme Select Star SQL (en anglais).

Si vous êtes déjà à l'aise avec le SQL, vous pouvez plonger directement dans l'enquête ci-dessous !

Les détectives SQL expérimentés commencent ici

Un crime a eu lieu et l'inspecteur a besoin de votre aide. Il vous a donné le rapport de la scène de crime, mais vous l'avez perdu. Vous vous souvenez vaguement qu'il s'agissait d'un meurtre (murder) qui a eu lieu le 15 janvier 2018 (20180115) et qu'il s'est déroulé à SQL City. Commencez par récupérer le rapport de scène de crime correspondant dans la base de données du commissariat.

Explorer la structure de la base de données

Les utilisateurs expérimentés peuvent souvent utiliser des requêtes pour déduire la structure d'une base de données. Chaque système de gestion de base de données a sa propre façon de gérer ces informations. Le SQL Murder Mystery utilise SQLite. Utilisez cette commande SQL pour trouver les tables de la base de données.

En plus de connaître le nom des tables, vous devez savoir comment chaque table est structurée. Voici comment procéder avec SQLite.
